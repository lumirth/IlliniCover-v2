# iOS design thesis

## Visual thesis

A low-attention Green Street utility: large decisive prices on calm native
surfaces, with blue reserved for action, purple for estimates, green for
confirmation, and red for correction.

## Content plan

1. The Bars tab answers the price/source question before anything else.
2. Venue detail exposes evidence, vibes, deals, and contribution context.
3. Deals stays a separate nightly slate, including venues with no current deal.
4. Settings contains account, preferences, IlliniCover Blue, and handbook.

## Interaction thesis

- Native context menus make common reporting paths available without adding
  persistent chrome.
- Report sheets open at a useful middle detent and expand only for optional
  detail.
- One short haptic and one restrained state transition acknowledge an action;
  Reduce Motion removes decorative movement.

The app uses semantic system backgrounds, Dynamic Type, native Form/List/Menu,
and no custom navigation or menu engine. Expo-specific focus and layout
workarounds are deliberately absent.
